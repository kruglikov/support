

# Digiteum (Symfony + MySQL)


**What you will do**  
Design and build backend services in modern PHP using Symfony and Symfony components.  
Work directly with **MySQL**, including schema design, hand written SQL and query tuning, alongside Doctrine ORM where it fits.  
Build REST APIs with OpenAPI specifications generated from the code and keep those specifications accurate.  
Work test first. Every fix ships with a test that proves it, and recurring classes of bugs get a static analysis rule that prevents their return.  
Maintain static analysis at the strictest level with no suppressions.  
Modernise legacy PHP code without breaking production.  
Integrate third party systems such as payment, accounting, CRM and supplier platforms.  
Review pull requests and improve the quality of design, naming and testing.  
**Our stack**  
Modern PHP with strict types, Symfony and Symfony components, Doctrine ORM and direct SQL on MySQL.  
PHPStan at level max, PHP CS Fixer, Rector and PHPUnit.  
Git and GitHub.  
Linux on the server and desktop, with Docker or Podman containers and LXC.  
AI assisted code review, triage and development tooling.  
**What we are looking for**  
**Essential**  
8+ years of commercial PHP experience, the majority on PHP 8. You are fluent in the language, including types, generics via static analysis, closures, iterators, attributes, enums, readonly and the standard library. You are ZCE certified or demonstrably at that level.  
TDD is a habit, not an aspiration. You write the failing test first and can explain why.  
Strong object oriented design and SOLID principles, applied with judgement rather than as slogans.  
Maximum type safety. You work with strict types everywhere, no mixed, no suppressions and PHPStan at level max. You can write a custom PHPStan rule when the codebase needs one.  
Strong MySQL skills, including schema design, writing and tuning raw SQL, reading execution plans and indexing. Your database experience is not limited to ORM mediated access.  
Solid Symfony and Doctrine experience, including the judgement to know when to bypass the ORM.  
Linux on both server and desktop as your daily environment. You are fluent in the shell.  
Ability to work with legacy PHP code when required, including reading it, fixing it safely and bringing it under test.  
Git with branch and pull request discipline.  
Fail fast and YAGNI applied with judgement.  
Ability to use AI assisted development tooling while maintaining full comprehension and control of the code, and to push back on and guide the tooling for optimal outcomes.  
Clear written communication.  
**Desirable**  
Experience migrating legacy PHP applications to modern Symfony.  
**Message driven architecture or DDD**.  
Mutation testing, Rector and architecture rules.  
Payment gateway, accounting, CRM or supplier feed integrations, including SOAP.  
Structured logging and observability.
